## ⚙️ Getting Started

No build tools needed! This is a pure HTML/CSS/JS project.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shindevaishnvi/portfolio.git
   ```

2. **Open in browser:**
   ```
   Just open index.html in any modern browser.
   ```

3. *(Optional)* Use a local server for best results:
   ```bash
   # With VS Code Live Server extension, or:
   npx serve .
   ```
